# skills

Agent skills by [horus.dev](https://horus.dev).

## Install

```sh
npx skills add horusdotdev/skills
```

Install a single skill:

```sh
npx skills add horusdotdev/skills --skill horus-mcp
```

## Skills

### personal

- [`horus-mcp`](skills/personal/horus-mcp/SKILL.md): use the `horus` Code Mode MCP server first when looking for MCP tools.
